更新日誌
========

[0.3.1] - 2026-02-11
--------------------
- 統一 `layout` + `grid` + `@video` + `@iframe` 的欄位填滿與外距行為，保持左右對齊
- `layout` 改用共用 CSS Grid 欄位模板，比例參數透過 `fr` 數值對應

[0.3.0] - 2026-02-10
--------------------
- 新增混合排版語法：``:::layout[...]``、``@slot``、``:::end-layout``
- 新增欄寬百分比控制：可自訂左右/多欄比例，並自動正規化為 100%
- 新增同列多欄能力：可在同一行混排多張圖片、文字、影片與 iframe

[0.2.1] - 2026-02-10
--------------------
- 強化自適應排版

[0.2.0] - 2025-12-13
--------------------
- 新增行動裝置支援：直式畫面自動切換佈局
- 新增隱藏式側邊欄：透過漢堡按鈕展開/收合
- 新增頂部工具列：顯示標題與選單按鈕

[0.1.0] - 2024-12-11
--------------------
- 新增影片與 iframe 響應式設計
- 影片：寬度 100%，保持原始比例
- iframe：寬度 100%，固定 16:9 比例

[0.0.0] - 2024-12-09
--------------------
- 初始版本發布
- 左右分屏佈局
- Markdown 內容管理
- 自訂語法：``:::grid``、``@video``、``@iframe``
