更新日誌
========

[0.6.7] - 2026-02-25
--------------------
- `@iframe` 新增非影片型嵌入的右下角極簡 `Full` 圖示按鈕，點擊可啟用全螢幕
- `@iframe` 影片型嵌入（YouTube/Vimeo 等）不顯示自訂按鈕，避免與播放器原生全螢幕重複
- 統一全螢幕事件流程：由 `app.js` 以事件委派處理 `data-iframe-action=\"fullscreen\"`
- 簡化內容區留白規則：桌機左右固定 24px、手機左右固定 16px；內容最大寬度調整為 1440px

[0.6.6] - 2026-02-23
--------------------
- 新增 `@gif[title](url)` 語法：以影片實作 GIF-like 播放（自動播放、循環、靜音、行動裝置內嵌）
- 擴充影片 MIME 推斷：`@video` / `@gif` 依副檔名輸出對應 `source type`（支援 `mp4/webm/ogg/ogv/mov`）
- 更新專案資源路徑改寫：`@gif[](assets/...)` 與既有媒體指令一致支援 `assets/` 自動補路徑

[0.6.5] - 2026-02-23
--------------------
- 新增 `@video` 預設播放屬性：預設靜音（`muted`）、`playsinline`、`preload="metadata"`
- 修正左側大綱標題在中文路由下的顯示：統一 hash 片段解碼流程，避免顯示 URL 編碼字串
- 擴充文件大綱層級：由 `h1~h3` 改為 `h1~h6`

[0.6.4] - 2026-02-23
--------------------
- 新增 Markdown 表格樣式：內容區表格預設滿寬顯示（`width: 100%`）
- 調整表格配色規則：僅表頭列為灰底，其餘列維持白底

[0.6.3] - 2026-02-22
--------------------
- 調整一般圖片顯示規則：內容區圖片預設左右滿寬（`width: 100%`）
- 圖片高度改為依寬度等比例縮放（`height: auto`）

[0.6.2] - 2026-02-22
--------------------
- 新增 inline 分行語法：`@br` 與 `@br(n)`（支援一次多行，最大 6 行）
- 更新 Markdown 擴充支援清單與 README 語法說明

[0.6.1] - 2026-02-19
--------------------
- 重構版面容器階層：改為「全寬上方工具列 + 下層工作區（左大綱/中內容/右導航）」
- 右側導航改為位於工具列下方，避免桌機與直式版在容器起始位置不一致
- 手機版位移邏輯改由工作區統一處理，移除內容區重複的頂部補償

[0.6.0] - 2026-02-19
--------------------
- 新增左側文件大綱面板：自動擷取 `h1~h3` 並建立巢狀章節結構
- 新增大綱收合/展開互動與章節定位（符號改為 `⌵` / `▸`）
- 新增大綱 active 同步：內容捲動時自動高亮目前章節並保持可視
- 調整版面捲動模型：左側大綱與中央內容改為獨立捲動
- 響應式優化：手機版隱藏左側大綱，維持閱讀區優先

[0.5.0] - 2026-02-19
--------------------
- 重構 Markdown 擴充解析流程：改為單一 parser 管線處理 `grid、layout、圖片、影片、iframe`
- 移除 `app.js` 內圖片標題 DOM 後處理，改由 parser 直接輸出語義化 `figure/figcaption`
- `@cover` 語法更新為 `@cover(url)`（不相容舊語法 `@cover[url]`）
- `![title](url)` 圖片標題改為解析階段產生，連續圖片不需空行也可正確顯示
- 統一 `image-grid` 內媒體容器 class 與 justify 寬度計算邏輯
- 強化 `grid` 內 `video/iframe` 的容器排版規則，混合媒體時欄位分配更穩定
- 修正示例內容中影片誤用 `![]()` 的語法，改為 `@video[]()` 以避免被瀏覽器當作圖片處理
- 將面板樣式從 `style.css` 拆分到獨立 `css/panels.css`，分離版面框架與內容樣式

[0.4.1] - 2026-02-19
--------------------
- 新增圖片標題排版：`![title](url)` 會將 `title` 置中顯示於圖片下方
- `@video` 語法更新為 `@video[title](url)`（不相容舊語法）
- `@iframe` 語法更新為 `@iframe[title](url)`（不相容舊語法）

[0.4.0] - 2026-02-13
--------------------
- 新增 `@cover[url]` 語法，用於首頁扉頁封面

[0.3.1] - 2026-02-11
--------------------
- 統一 `layout` + `grid` + `@video` + `@iframe` 的欄位填滿與外距行為，保持左右對齊
- `layout` 改用共用 CSS Grid 欄位模板，比例參數透過 `fr` 數值對應

[0.3.0] - 2026-02-10
--------------------
- 新增混合排版語法：``:::layout[...]``、``@slot``、``:::end-layout``
- 新增欄寬百分比控制：可自訂左右/多欄比例，並自動正規化為 100%
- 新增同列多欄能力：可在同一行混排多張圖片、文字、影片與 iframe

[0.2.1] - 2026-02-10

- 強化自適應排版

[0.2.0] - 2025-12-13

- 新增隱藏式側邊欄：透過漢堡按鈕展開/收合
- 新增頂部工具列：顯示標題與選單按鈕
